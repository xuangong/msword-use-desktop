# 模拟样本说明

为了测试 `extract-format` skill 的产出形态，这里没有跑真 Word 文档（dev 环境没有合适的公文样本），而是**手工合成**了一份典型的国务院通知体公文（13 段），按 SKILL.md 定义的工作流走完三遍 Pass，得到 `sample-gongwen-profile.md`。

合成规则：
- 段 1: 红头（居中红色大字）
- 段 2: 发文字号（居中楷体）
- 段 3: 红线分隔（实际是带下边框的空段——这种 Word 公文常用 trick）
- 段 4: 标题（居中黑体二号）
- 段 5: 主送机关（顶格）
- 段 6: 引导段（首行缩进 2 字仿宋）
- 段 7-9: 编号正文（"一、""二、""三、"列表）
- 段 10: 普通正文段
- 段 11: 落款单位（右对齐）
- 段 12: 成文日期（右对齐）
- 段 13: 抄送（小字 + 上下边框）

合成数据**故意混入**：
- 段 8 里有一处粗体强调（多 run）
- 段 10 莫名比正文小 1pt（异常 / 存疑）

这样 Pass 2 可以演示三种耦合度判断都触发到。

## 怎么读

直接看 `sample-gongwen-profile.md`。这个文件就是 skill 跑完后**应该**生成的产物形态。
